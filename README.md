# 房屋影片自動剪輯（Housing Cut）

> 動畫引擎：[GSAP](https://gsap.com/)（開頭逐字出現、畫線、轉場緩動）
> 最高畫質輸出：[HyperFrames](https://hyperframes.heygen.com/)（HeyGen 開源，HTML 逐格渲染成 MP4）

把 FF14 房屋裝潢的錄影素材丟進去，自動挑出好用的片段、加上縮放與平移、開頭標題，
可以在時間軸上微調，最後直接匯出 MP4。所有處理都在你的瀏覽器裡完成，影片不會上傳到任何地方。

## 怎麼開啟

- **線上版**：直接打開發佈的網址。
- **自己電腦上**：解壓縮後，用 **Chrome 或 Edge** 雙擊打開 `index.html` 就能用，不需要安裝任何東西。
  （Safari、Firefox 也能剪輯，但匯出影片建議用 Chrome／Edge，會輸出 MP4。）

## 使用流程

1. **匯入素材**：按「匯入素材」或直接把影片拖進視窗。依檔名排序，FF14 錄影檔名裡的時間會被當成拍攝順序。
2. **自動分析**：每支素材會以 4 倍速在背景分析（約為影片長度的 1/3 時間），找出：
   - 靜止的畫面（紫色）、運鏡（綠色）、太快或太晃的地方（灰色）
   - 白色滑鼠游標出現的時間（紅色）、遊戲介面出現的時間（藍色），自動剪輯會避開
3. **分場景**：素材依拍攝時間排好後，自動分成幾個場景（例如庭園、室內）。拍攝時間相隔太久，或畫面的色彩、亮度明顯換了，都算新場景。
   素材區會標出「場景 1、場景 2…」，分錯了可以按素材上的「分場景」或場景標題旁的「併回上一個」修正。換場景時預設用黑場轉場，鏡頭重排也只在同一個場景裡進行。
   「自動剪輯」分頁可調「畫面換場景的判斷靈敏度」（調到 0 = 只看拍攝時間）。
4. **自動剪輯**：分析完會自動剪好第一版。可在「自動剪輯」分頁調整目標長度、節奏、縮放幅度後按「重新自動剪輯」。
5. **微調**（快捷鍵在時間軸上方「快捷鍵」）：
   - 拖鏡頭的左右邊緣修剪長度（會吸附到播放位置和音樂拍點）；`S` 在播放位置分割
   - `Ctrl`／`Shift` + 點可以多選，右邊的修改會一次套用到全部選取的鏡頭；`Ctrl+A` 全選
   - 「推近／縮放的目標點」：自動對準細節最多的地方，也可以按「在預覽畫面上點一下」自己指定
   - 👍 好鏡頭、👎 不要這種、「換一個」（換成同一支素材或同場景裡還沒用到、分數最高的片段），都會馬上學起來
   - 「為什麼選這個」會說明自動剪輯挑這個片段、用這個效果的原因
   - 時間軸上點鏡頭 → 右邊可以改開始時間、長度、效果（推近／拉遠／平移／保留原運鏡）、速度、黑場轉場、畫面文字
   - 拖曳鏡頭可以換順序；Delete 鍵刪除；Ctrl+Z 復原
   - 左邊點素材 → 可以看原始影片，從任意位置「加入鏡頭」，或把有介面、穿牆的段落「排除」
6. **轉場**：「轉場」分頁有 12 種（直切、疊化、慢速淡化、黑場、白場、模糊、圓形掃描、向右／向左擦除、推移、縮放穿越、閃白）。
   點一個再「套用到選取的鏡頭」或「套用到全部」。鏡頭設定裡也能個別改。自動剪輯可選「依學到的習慣」「換場景用黑場，其他直切」「多種轉場混合」「全部用同一種」。
7. **開頭片尾**：8 種開頭模板（經典置中、逐字浮現、畫線強調、電影黑邊、打字機、左下資訊卡、大字縮放、不顯示），可加第三行（伺服器、地址）。每種模板都能選位置（跟模板一樣／上方／中間／下方／左下角）。片尾可選樣式與文字。動畫由 GSAP 時間軸驅動。
8. **濾鏡特效**：10 種濾鏡（清新、暖陽、冷調、電影感、復古、夜晚、夢幻、奶油、黑白…），「濾鏡強度」0～200%，有色調的濾鏡另外可調「色調濃度」。特效有暗角、柔光、飄浮光點、落花、底片顆粒、電影黑邊，可調強度。
9. **音樂**：背景音樂結尾會自動淡出。
10. **防抖**：運鏡鏡頭預設會自動防抖（時間軸上標「防抖」）。也可以在鏡頭設定裡個別開關、調整強度。
   強度越高、畫面越穩，但會放大越多（約 4%～12%）。分析時會以 0.5 倍速播放該段，所以要等一下。分析失敗會自動重試，還是失敗的鏡頭標「防抖失敗」，之後按播放或匯出會再試。
11. **學習**：「學習」分頁
   - 「記住這次的修改」：比較自動剪輯的結果和你改過的版本。匯出影片時也會自動記住。學的內容：
     - 選素材：你留下／刪掉／新增哪種片段（小模型會依此替候選片段打分）、每支素材用幾個鏡頭、影片總長度、運鏡佔比
     - 順序：照拍攝順序的程度、靜止和運鏡怎麼接、用哪種鏡頭開場
     - 轉場：同一支素材內、換素材、換場景時各用哪種轉場、多長
     - 畫面：鏡頭長短、短鏡頭比例、縮放幅度、推近／平移比例；常用的開頭、片尾、濾鏡（開新專案時預先選好）
   - 「加入參考影片」：上傳你喜歡的別人剪好的影片，分析鏡頭長度、推近／平移比例、直切／黑場／疊化的比例、靜止和運鏡怎麼接。
   - 「自動剪輯」分頁勾選「套用學到的風格」，重新自動剪輯時就會用學到的數值。
   - 還會學：運鏡頭尾習慣裁多少、每種效果的縮放大小、什麼樣的畫面你會用推近或平移（看畫面細節分布的小模型）
   - 在素材區把場景標成「庭園」「室內」，會分開學兩種場景的剪法，也會記住它們的色彩，之後自動猜類型
   - 可以有好幾套風格（「另存新風格」），每次學習前會自動備份，可以「退回上一版」
   - 學習資料存在瀏覽器裡（換瀏覽器或清除網站資料就會不見），可以「匯出學習資料」備份、在別台電腦「匯入」。
12. **匯出**（「匯出」分頁選方式）：
   - **逐格輸出（預設）**：一格一格畫好再編碼成影片，**不會掉格**，30 或 60 fps。一般 MP4（H.264）素材會直接依序解碼，比較快；其他格式改用逐格跳轉，比較慢。
     需要 Chrome／Edge 94 以上（WebCodecs）。背景音樂優先編成 AAC，瀏覽器不支援時改用 Opus（Chrome、VLC、YouTube 都能播，少數剪輯軟體不吃 Opus）。
   - **即時錄製**：邊播邊錄（2 分鐘的影片要錄 2 分鐘），錄製時請讓分頁保持在最前面，電腦忙的時候可能掉格。瀏覽器不支援逐格輸出時會自動改用這個。
   - 「下載 HyperFrames 專案」：打包成 HyperFrames 專案，在自己電腦上用 `npx hyperframes render` 逐格渲染，**不會掉格、畫質最好**。需要 Node.js 22 以上和 FFmpeg，步驟在專案裡的 README.md。也可以用 HyperFrames Studio 繼續編輯。
13. **我的專案**（右上「儲存專案」／「我的專案」，`Ctrl+S` 快速儲存）：專案依資料夾整理（可以用 `/` 建子資料夾，例如「客戶/小明」），加標籤；可以搜尋名稱、資料夾、標籤、素材檔名、畫面文字，依修改時間／名稱／長度排序；開啟、複製、改名、拖到別的資料夾、刪除。專案存在這個瀏覽器裡（IndexedDB）。
   - 「下載資料夾」：打包成 `專案名/` 資料夾（.zip），內含 `project.json`、`cover.jpg`、`music/`（自己的音樂）、`sounds/`（自己的音效），勾選後也能包含 `media/` 影片素材。支援的瀏覽器（Chrome／Edge 獨立分頁）可以「存到電腦」直接寫進電腦上的資料夾。
   - 「匯入」：選整個專案資料夾或 .zip（也能選舊版的 .json）。沒有 media 的話，開啟後再匯入同檔名的素材就會自動對上。
14. **分軌時間軸**：影片、文字、特效、音樂、環境音各一軌。
   - 拖鏡頭換順序（會顯示插入位置），拖鏡頭邊緣修剪；點或拖尺規移動播放位置。
   - 文字、特效、音樂、環境音：拖曳移動、拖左右邊緣改長度，會吸附到播放位置、鏡頭接點和音樂拍點；點一下在右邊編輯（文字樣式／位置、特效種類和強度、音樂從第幾秒播、音量），`Delete` 刪除。
   - 把左邊的素材拖到影片軌：插入一個鏡頭（自動挑這支素材裡還沒用過、分數最高的片段）。
   - 把音樂庫的音樂拖到音樂軌、音效拖到環境音軌：從放開的位置開始播。
   - 「＋ 文字」「＋ 特效」在播放位置加一段。鏡頭設定裡的「畫面文字」會變成跟著那個鏡頭的文字（🔗），拖動後變成獨立的文字。
15. **自動存檔**：每幾秒自動存在瀏覽器裡，下次打開會問要不要繼續。用「匯入素材」按鈕（Chrome／Edge）或拖進來的素材會記住檔案位置，按「找回素材檔」允許讀取就能接著剪；分析過的素材也會記住結果，不用重新分析。
16. **直式 9:16**：「匯出」分頁選畫面比例。每個鏡頭依目標點決定保留素材的哪一塊，平移會變成左右橫掃；網頁匯出和 HyperFrames 都支援。
17. **音樂拍點**：選了背景音樂會自動找拍點（時間尺上的小點），自動剪輯會把剪接點對齊拍點；也可以在「音樂」分頁按「把剪接點對齊拍點」。
18. **免費音樂與音效庫**（「音樂」分頁）：內建 112 個 CC0／公有領域的音樂和音效，可以免費商用、不用標示作者。
   - 音樂（8 類）：管弦樂、鋼琴、室內樂・弦樂、吉他・民謠、輕快・Lo-fi・爵士、奇幻・冒險、音樂盒、氛圍・療癒。古典曲目是 Musopen 的公有領域錄音（布拉姆斯、葛利格、孟德爾頌、蕭邦、巴哈…）
   - 音效（9 類）：流水・噴泉、雨聲、海浪、風聲、鳥鳴・森林、夜晚・蟲鳴、壁爐・營火、風鈴、室內・生活。都整理成可以無縫循環的 75 秒片段
   - 「環境音效」可以疊最多 3 層在音樂下面（例如溪流＋鳥鳴），各自調音量，整支影片循環播放、頭尾淡入淡出；網頁匯出和 HyperFrames 都會帶上
   - 每一首的出處在 `audio/CREDITS.md`，或在音樂庫按「看每一首的來源」
   - 想加更多：在 `tools/audio_sources.json` 加一筆（先到來源頁確認是 CC0／公有領域），執行 `python3 tools/build_audio_library.py`
19. **一次做 3 個版本**（「自動剪輯」分頁）：「慢慢欣賞」「節奏輕快」「60 秒精華」，可以在時間軸預覽，選一個用；你選的風格會被學起來。
20. **短影音版**：從目前的時間軸挑分數最高的鏡頭，做成直式 45 秒；完整版會自動存進「版本」。
21. **更聰明的自動剪輯**：去掉角度幾乎一樣的重複畫面、判斷白天／夜晚（素材區場景旁的 ☀／🌙，點一下可以改）並把白天排前面、依目標長度（和背景音樂長度）調整鏡頭長短。
22. **音樂推薦和最好聽的一段**：「音樂」分頁依畫面（庭園／室內、白天／夜晚）推薦音樂和環境音，可一鍵套用；選了音樂會自動避開長前奏，結尾盡量落在樂句結束。
23. **鏡頭進階設定**（鏡頭分頁）：
   - 自訂路徑：設定起點畫框和終點畫框（在預覽上拖曳移動、滾輪縮放），做斜向移動、推近再橫移
   - 速度曲線（頭尾慢中間快、慢慢加速、慢慢減速）和結尾定格
   - 調色：亮度、對比、飽和度、色溫；「自動配色」讓白天、夜晚各自顏色一致
   - 複製效果／貼上效果（Alt+C／Alt+V），可以一次貼到好幾個鏡頭
   - 標註：在畫面上點一個位置，加上箭頭和文字（例如家具名稱），推近、平移時跟著移動
   - 畫面合成：日夜對比（分隔線從右邊掃進來）、子母畫面；「自動找一組日夜對比」會找角度最像的白天、夜晚鏡頭
24. **浮水印・簽名**（開頭片尾分頁）：文字或 Logo 圖片，放在角落，整支影片都顯示。
25. **匯出預設**：YouTube 1080p／4K、Shorts／Reels／TikTok、Instagram 方形 1:1、直式 4:5；超過平台建議長度會提醒。
26. **封面圖和 YouTube 章節**：自動挑 3 個好看的畫面加上標題，下載成 1280×720 JPG；章節依場景產生「0:00 庭園」這樣的文字，可以直接改再複製。
27. **流暢預覽**：做一份 640×360 的預覽檔，素材多或電腦慢時預覽更順；匯出還是用原始畫質（只支援 MP4／H.264 素材）。
28. **版本**：上方「版本」可以把目前的剪輯存起來、之後回到某個版本（回去前會自動備份目前的）。
29. **導覽和手機版**：上方「？」重看使用導覽；手機上版面會改成上下排列。

### 常改的地方

- **想讓長鏡頭更長**：`js/auto.js` 的 `HC.TUNE.longStill`（秒）
- **想讓短鏡頭更短**：`HC.TUNE.shortStill`
- **鏡頭稍微動一下就被判成「太快」**：調高 `HC.TUNE.fastBase` 或在介面把「鏡頭晃動容忍度」拉高
- **介面偵測太敏感／抓不到**：`js/analyze.js` 的 `HC.UI`（`minBlocks` 越大越不敏感）
- **防抖放大太多**：`js/stab.js` 的 `HC.stabCrop`
- **你的修改影響學習的比重**：`js/learn.js` 開頭的 `W_EDIT`（手動修改）、`W_REF`（參考影片）
- **游標沒被抓到**（例如 Windows 顯示縮放 125% 以上）：放大 `js/analyze.js` 裡 `HC.CURSOR` 的數字
- **新增開頭模板**：`js/effects.js` 的 `HC.TITLE_TEMPLATES`，每個模板是一段 GSAP 時間軸（`build(tl, g, d)`）
- **新增轉場**：`js/effects.js` 的 `HC.TRANSITIONS`、`HC.drawTransition()`（網頁）和 `HC.hfTransition()`（HyperFrames）
- **新增濾鏡**：`js/effects.js` 的 `HC.FILTERS`（CSS filter 字串；強度滑桿會自動把每個參數往原色內插）
- **場景分得太細／太粗**：介面上的「畫面換場景的判斷靈敏度」，或 `js/auto.js` 的 `HC.computeScenes()`
- **新增推近／平移效果**：`js/render.js` 的 `drawShot()` 裡 `switch (s.mode)`，再到 `index.html` 的效果選單加選項

## 已知限制

- 只能「剪掉」有遊戲介面的片段，沒辦法把介面擦掉。錄影前按 Scroll Lock 隱藏 UI 最省事。
- 介面偵測靠「鏡頭在動、某塊畫面卻不動」來判斷，所以鏡頭完全靜止時看不出來（會沿用前後幾秒的判斷），半透明、沒有圖案的介面也可能漏掉。漏掉的請用「排除」標記。
- 防抖只修正上下左右的晃動，鏡頭轉動造成的透視變化修不了；前後景移動速度差很多的畫面（穿過樹叢、拱門）效果會打折。
- 學習是用統計和簡單的模型，不是大型 AI；需要累積幾次修改才看得出效果。移除參考影片紀錄不會把已經學到的風格倒回去，要重來請用「全部重設」。
- YouTube 等網址無法直接分析，請下載後上傳影片檔。
- 逐格輸出的速度依電腦而定，通常是影片長度的 1～4 倍；MKV、分段式 MP4、HEVC 素材會走比較慢的跳轉方式。
- 自動分場景是看畫面色彩和亮度，夜景庭園和昏暗室內這種很像的畫面可能分不出來，請手動「分場景」。
- 原始素材的聲音不會放進成品，只會用你選的背景音樂。
