# 房屋影片自動剪輯（Housing Cut）

> 動畫引擎：[GSAP](https://gsap.com/)（開頭逐字出現、畫線、轉場緩動）
> 最高畫質輸出：[HyperFrames](https://hyperframes.heygen.com/)（HeyGen 開源，HTML 逐格渲染成 MP4）

把 FF14 房屋裝潢的錄影素材丟進去，自動挑出好用的片段、加上縮放與平移、開頭標題，
可以在時間軸上微調，最後直接匯出 MP4。所有處理都在你的瀏覽器裡完成，影片不會上傳到任何地方。

## 怎麼開啟

- **線上版**：直接打開發佈的網址。
- **自己電腦上**：解壓縮後，用 **Chrome 或 Edge** 雙擊打開 `index.html` 就能用，不需要安裝任何東西。
  （Safari、Firefox 也能剪輯，但匯出影片建議用 Chrome／Edge，會輸出 MP4。）

## 使用流程

1. **匯入素材**：按「匯入素材」或直接把影片拖進視窗。依檔名排序，FF14 錄影檔名裡的時間會被當成拍攝順序。
2. **自動分析**：每支素材會以 4 倍速在背景分析（約為影片長度的 1/3 時間），找出：
   - 靜止的畫面（紫色）、運鏡（綠色）、太快或太晃的地方（灰色）
   - 白色滑鼠游標出現的時間（紅色）、遊戲介面出現的時間（藍色），自動剪輯會避開
3. **自動剪輯**：分析完會自動剪好第一版。可在「自動剪輯」分頁調整目標長度、節奏、縮放幅度後按「重新自動剪輯」。
4. **微調**：
   - 時間軸上點鏡頭 → 右邊可以改開始時間、長度、效果（推近／拉遠／平移／保留原運鏡）、速度、黑場轉場、畫面文字
   - 拖曳鏡頭可以換順序；Delete 鍵刪除；Ctrl+Z 復原
   - 左邊點素材 → 可以看原始影片，從任意位置「加入鏡頭」，或把有介面、穿牆的段落「排除」
5. **轉場**：「轉場」分頁有 12 種（直切、疊化、慢速淡化、黑場、白場、模糊、圓形掃描、向右／向左擦除、推移、縮放穿越、閃白）。
   點一個再「套用到選取的鏡頭」或「套用到全部」。鏡頭設定裡也能個別改。自動剪輯可選「依學到的習慣」「換場景用黑場，其他直切」「多種轉場混合」「全部用同一種」。
6. **開頭片尾**：8 種開頭模板（經典置中、逐字浮現、畫線強調、電影黑邊、打字機、左下資訊卡、大字縮放、不顯示），可加第三行（伺服器、地址）。片尾可選樣式與文字。動畫由 GSAP 時間軸驅動。
7. **濾鏡特效**：10 種濾鏡（清新、暖陽、冷調、電影感、復古、夜晚、夢幻、奶油、黑白…），特效有暗角、柔光、飄浮光點、落花、底片顆粒、電影黑邊，可調強度。
8. **音樂**：背景音樂結尾會自動淡出。
9. **防抖**：運鏡鏡頭預設會自動防抖（時間軸上標「防抖」）。也可以在鏡頭設定裡個別開關、調整強度。
   強度越高、畫面越穩，但會放大越多（約 4%～12%）。分析時會以 0.5 倍速播放該段，所以要等一下。
10. **學習**：「學習」分頁
   - 「記住這次的修改」：比較自動剪輯的結果和你改過的版本。匯出影片時也會自動記住。學的內容：
     - 選素材：你留下／刪掉／新增哪種片段（小模型會依此替候選片段打分）、每支素材用幾個鏡頭、影片總長度、運鏡佔比
     - 順序：照拍攝順序的程度、靜止和運鏡怎麼接、用哪種鏡頭開場
     - 轉場：同一支素材內、換素材、換場景時各用哪種轉場、多長
     - 畫面：鏡頭長短、短鏡頭比例、縮放幅度、推近／平移比例；常用的開頭、片尾、濾鏡（開新專案時預先選好）
   - 「加入參考影片」：上傳你喜歡的別人剪好的影片，分析鏡頭長度、推近／平移比例、直切／黑場／疊化的比例、靜止和運鏡怎麼接。
   - 「自動剪輯」分頁勾選「套用學到的風格」，重新自動剪輯時就會用學到的數值。
   - 學習資料存在瀏覽器裡（換瀏覽器或清除網站資料就會不見），可以「匯出學習資料」備份、在別台電腦「匯入」。
11. **匯出**：
   - 「匯出影片」：在網頁裡即時錄製（2 分鐘的影片要錄 2 分鐘），錄製時請讓分頁保持在最前面。電腦忙的時候可能掉格。
   - 「下載 HyperFrames 專案」：打包成 HyperFrames 專案，在自己電腦上用 `npx hyperframes render` 逐格渲染，**不會掉格、畫質最好**。需要 Node.js 22 以上和 FFmpeg，步驟在專案裡的 README.md。也可以用 HyperFrames Studio 繼續編輯。
12. **儲存專案**：存成 `.json`，下次「開啟專案」後再匯入同檔名的素材就能接著剪。

## 檔案結構（想自己改的話）

| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面結構、所有按鈕與設定欄位 |
| `css/style.css` | 外觀與顏色（開頭的 `:root` 改配色） |
| `js/state.js` | 專案資料、復原／重做、縮圖 |
| `js/analyze.js` | 素材分析：畫面變化、鏡頭移動方向、白色游標偵測（`HC.CURSOR`）、遊戲介面偵測（`HC.UI`） |
| `js/stab.js` | 防抖：逐格量測鏡頭晃動、平滑、計算補償（`HC.stabCrop` 放大倍率） |
| `js/learn.js` | 學習：從手動修改和參考影片更新剪輯風格（選素材、順序、轉場、畫面）、挑片段的小模型 |
| `js/effects.js` | 轉場、濾鏡、特效、開頭／片尾模板（GSAP）。網頁和 HyperFrames 專案共用同一份 |
| `js/hyperframes.js` | 匯出 HyperFrames 專案（index.html + 素材，打包成 zip） |
| `js/auto.js` | 自動剪輯規則（`HC.TUNE` 調整靜止／太快的門檻、長短鏡頭秒數） |
| `js/render.js` | 畫面合成（縮放、平移、黑場、標題字）、播放、匯出 |
| `js/ui.js` | 介面互動、時間軸、存檔 |

### 常改的地方

- **想讓長鏡頭更長**：`js/auto.js` 的 `HC.TUNE.longStill`（秒）
- **想讓短鏡頭更短**：`HC.TUNE.shortStill`
- **鏡頭稍微動一下就被判成「太快」**：調高 `HC.TUNE.fastBase` 或在介面把「鏡頭晃動容忍度」拉高
- **介面偵測太敏感／抓不到**：`js/analyze.js` 的 `HC.UI`（`minBlocks` 越大越不敏感）
- **防抖放大太多**：`js/stab.js` 的 `HC.stabCrop`
- **你的修改影響學習的比重**：`js/learn.js` 開頭的 `W_EDIT`（手動修改）、`W_REF`（參考影片）
- **游標沒被抓到**（例如 Windows 顯示縮放 125% 以上）：放大 `js/analyze.js` 裡 `HC.CURSOR` 的數字
- **新增開頭模板**：`js/effects.js` 的 `HC.TITLE_TEMPLATES`，每個模板是一段 GSAP 時間軸（`build(tl, g, d)`）
- **新增轉場**：`js/effects.js` 的 `HC.TRANSITIONS`、`HC.drawTransition()`（網頁）和 `HC.hfTransition()`（HyperFrames）
- **新增濾鏡**：`js/effects.js` 的 `HC.FILTERS`（CSS filter 字串）
- **新增推近／平移效果**：`js/render.js` 的 `drawShot()` 裡 `switch (s.mode)`，再到 `index.html` 的效果選單加選項

## 已知限制

- 只能「剪掉」有遊戲介面的片段，沒辦法把介面擦掉。錄影前按 Scroll Lock 隱藏 UI 最省事。
- 介面偵測靠「鏡頭在動、某塊畫面卻不動」來判斷，所以鏡頭完全靜止時看不出來（會沿用前後幾秒的判斷），半透明、沒有圖案的介面也可能漏掉。漏掉的請用「排除」標記。
- 防抖只修正上下左右的晃動，鏡頭轉動造成的透視變化修不了；前後景移動速度差很多的畫面（穿過樹叢、拱門）效果會打折。
- 學習是用統計和簡單的模型，不是大型 AI；需要累積幾次修改才看得出效果。移除參考影片紀錄不會把已經學到的風格倒回去，要重來請用「全部重設」。
- YouTube 等網址無法直接分析，請下載後上傳影片檔。
- 匯出是即時錄製，畫格會跟著電腦效能走；電腦太忙時可能偶爾掉格。
- 原始素材的聲音不會放進成品，只會用你選的背景音樂。
